# Dark mode အသုံးပြုနည်း

မွမ်းမံသည့်နေ့: 2026-10-03

Customer အတွက် **Profile → Appearance** ကို ဖွင့်ပါ။ Login မလုပ်ထားလည်း ရွေးနိုင်ပါတယ်။ Admin အတွက် **Settings → THIS DEVICE → Appearance** မှာ ရွေးနိုင်ပါတယ်။

- **Light** — အလင်းရောင်နောက်ခံနဲ့ သုံးပါမယ်။
- **Dark** — မှောင်ရောင်နောက်ခံနဲ့ သုံးပါမယ်။
- **System** — ဖုန်းရဲ့ Light/Dark setting အတိုင်း လိုက်ပြောင်းပါမယ်။ ပထမဆုံးအသုံးပြုချိန် မူလရွေးချယ်မှုပါ။

ရွေးထားတာကို ဒီစက်မှာ မှတ်ထားပြီး app ပြန်ဖွင့်လည်း ပြန်သုံးပါတယ်။ Account ပြောင်းခြင်းကြောင့် appearance မပြောင်းပါ။ Shop settings နဲ့ တခြားအသုံးပြုသူတွေရဲ့ appearance ကို မပြောင်းပါ။

Shop၊ Wishlist၊ Cart၊ Checkout၊ Profile၊ form၊ dialog၊ loading နဲ့ Admin စာမျက်နှာတွေကို theme အလိုက် အရောင်ပြောင်းထားပါတယ်။ Logo၊ ပစ္စည်းဓာတ်ပုံနဲ့ invoice စာရွက်ကို မူရင်းအရောင်အတိုင်း ထိန်းထားပါတယ်။ Stripe ငွေပေးချေမှုစာမျက်နှာရဲ့ appearance ကိုလည်း Checkout theme အတိုင်း သတ်မှတ်ထားပါတယ်။

စမ်းသပ်မှု **49 ခုလုံး အောင်မြင်ပါတယ်**။ ဖုန်း/tablet simulator မှာ Light နဲ့ Dark Shop preview ကို စစ်ပြီးပါပြီ။ Preview ပစ္စည်းတွေက sample data ဖြစ်ပြီး တကယ့်ဓာတ်ပုံတွေ မပါပါ။ Live payment နဲ့ ဖုန်းအစစ်ပေါ် accessibility စစ်ဆေးမှု မပြီးသေးပါ။

လက်ရှိ update ကို publish မလုပ်ထားသေးပါ။ 40/40 အတွက် ကျန်တဲ့အတည်ပြုချက်တွေကို [UX အတည်ပြုစာရင်း](ux-acceptance.md) မှာ ကြည့်နိုင်ပါတယ်။
